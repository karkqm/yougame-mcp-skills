# yougame-mcp

MCP-сервер + два скилла для работы ИИ с форумом разработчиков **yougame.biz** (XenForo 2.3).

Сервер даёт инструменты доступа, локальную базу знаний и каталог инструментов разработки.
Скиллы дают регламент: `yougame-first` — гейт «сначала ресерч, потом код», `yougame-research` —
механика форума (хайды, файлообменники, навигация).

Идея простая: прежде чем писать дампер, инжектор, миксин или ESP, надо проверить, не написано ли
это уже — в локальной базе, в каталоге готовых инструментов и на форуме. Свой код пишется поверх
найденного и со ссылками на источники.

**Ставится по [AI-INSTALL.md](AI-INSTALL.md)** — там пошаговая инструкция, рассчитанная на то,
что установку выполняет сам ИИ-агент.

## Что умеет

### База знаний и гейт

| Инструмент | Назначение |
|---|---|
| `yg_plan` | Первый вызов по задаче: домен, поисковые запросы, id разделов, готовые инструменты, сессия ресерча |
| `yg_kb_search` | Поиск по локальной базе — решалась ли задача раньше |
| `yg_tools` | Каталог инструментов разработки по домену и виду |
| `yg_note` | Записать находку: факт, версия, грабли, код, пробел |
| `yg_ready` | Гейт: можно ли уже писать код; отдаёт список недостающего |
| `yg_report` | Итог ресерча со ссылками на источники |
| `yg_kb_add_tool` | Добавить найденный инструмент в базу |
| `yg_kb_export` | Выгрузить каталог в markdown |

### Форум

| Инструмент | Назначение |
|---|---|
| `yg_guide` | Регламент: лестница решений, порядок ресерча, хайды, файлообменники, каталог инструментов |
| `yg_auth_status` | Видит ли форум нашу сессию |
| `yg_login` | Открыть настоящее окно браузера со страницей входа и сохранить куки |
| `yg_logout` | Забыть сессию |
| `yg_categories` | Дерево категорий → разделов → подразделов |
| `yg_forum` | Список тем раздела: префиксы, авторы, ответы, просмотры, пагинация |
| `yg_thread` | Статья + комментарии в markdown, блоки кода, вложения, ссылки, хайды |
| `yg_post` | Одно сообщение по id |
| `yg_search` | Поиск XenForo с фильтрами по разделам, автору и дате (нужен вход) |
| `yg_page` | Любая страница форума в markdown |
| `yg_resources` | Все скачиваемые ресурсы темы + инструкция по каждому хостингу |
| `yg_download` | Скачивание: вложения форума и внешние обменники, с браузерным фолбэком |

Цепочка скачивания: резолвер хоста → прямой GET → поиск ссылки в HTML → окно браузера
(многошаговое: страница файла → ожидание → файл). Архивы, которые обменник не отдаёт целиком
(например workupload без аккаунта), качаются по файлам — в ответе массив `files`.

Промпт `yougame_research` — готовый сценарий «ресерч → реализация».

### Лестница решений

Порядок, который навязывает скилл `yougame-first` и проверяет `yg_ready`:

| Ступень | Инструмент | Останавливаешься, если |
|---|---|---|
| 0. Это домен yougame? | `yg_plan` (`inScope`) | нет — обычная работа, форум не нужен |
| 1. Уже решали? | `yg_kb_search` | в локальной базе есть ответ |
| 2. Инструмент уже есть? | `yg_tools` | задача закрывается готовым инструментом |
| 3. Есть на форуме? | `yg_search` → `yg_thread` | нашлась механика или исходник |
| 4. Ресерч закрыт? | `yg_ready` | `ready: true` |
| 5. Реализация | — | — |
| 6. Вернуть знание | `yg_kb_add_tool`, `yg_report` | — |

Гейт не тупик: пустой форум фиксируется как `yg_note kind="gap"`, крайний случай —
`yg_ready` с `force` и обязательной причиной, которая попадает в отчёт.

### База инструментов

Встроенный каталог (`src/kb/catalog.ts`) — стартовый набор того, что уже написано до тебя:
дамперы (Dumper-7, source2gen, Il2CppDumper, Scylla, java-агент), декомпиляторы
(Vineflower, dnSpyEx, JADX, Recaf), деобфускаторы (de4dot, Threadtear), хук-библиотеки
(MinHook, Detours, Harmony, Frida), модлоадеры (BepInEx, MelonLoader, Fabric, Forge),
маппинги, работа с памятью, анализ. Разложен по доменам: `minecraft-java`, `native-windows`,
`unity-mono`, `unity-il2cpp`, `unreal`, `source-engine`, `dotnet`, `android`, `roblox`,
`script`, `dma`, `reverse`, `web`, `gamedev`.

Каждый домен знает свои разделы форума и свой список «что обязательно выяснить до кода».
Найденное на форуме дописывается через `yg_kb_add_tool` и попадает в ту же выдачу.

### Что понимает парсер

- дерево разделов (`.block--category`, `.node--idN`) со статистикой и подфорумами;
- список тем (`.structItem--thread`): префикс, автор, даты, ответы, просмотры, закреп/замок;
- тему целиком: теги, кастомные поля, блок «Краткое описание (ИИ-агент)» с самого форума,
  посты и комментарии в markdown, блоки кода отдельным полем, вложения с размерами;
- **хайды**: `.bbCodeBlock--hide` (нужен вход / ответ в теме / ранг) и скрытые от гостей ссылки
  (`.blockMessage-whlg`) — помечаются в тексте знаком 🔒 и складываются в массив `gates`;
- закрытые разделы: HTTP 403 + страница входа → ошибка `AUTH_REQUIRED`;
- внешние ссылки, обёрнутые в `/proxy.php?link=…`, разворачиваются в настоящий адрес.

## Установка

Нужен Node ≥ 18.17 (проверено на 18.20).

```bash
npm install
npm run build
npx playwright install chromium
```

> На Node 18 версии зависимостей зафиксированы: `playwright@1.49.x`, `cheerio@1.0.0`.
> Обновление Node до 20+ снимет эти ограничения — тогда можно поднять обе библиотеки.

### Подключение к Claude Code

Из каталога пакета:

```bash
claude mcp add yougame -- node "$(pwd)/dist/index.js"
```

Либо вручную: скопируй шаблон и подставь свой путь.

```bash
cp .mcp.json.example .mcp.json
```

```json
{
  "mcpServers": {
    "yougame": {
      "command": "node",
      "args": ["/абсолютный/путь/до/yougame-mcp-skills/dist/index.js"]
    }
  }
}
```

Путь должен быть абсолютным и вести на собранный `dist/index.js`.
Сам `.mcp.json` не версионируется — он у каждого свой.

### Установка скиллов

```bash
npm run install-skill -- --force
```

Копирует `skill/yougame-first` и `skill/yougame-research` в `~/.claude/skills/`.
Один скилл: `node scripts/install-skill.mjs yougame-first --force`.
После этого перезапусти клиент.

`yougame-first` подхватывается, когда просят **сделать** что-то из мира читов и реверса —
даже без упоминания форума. `yougame-research` — когда речь прямо о yougame.biz.

Всё разом (зависимости, сборка, скиллы):

```bash
npm run setup
```

## Авторизация

Пароль сервер не видит и не спрашивает. Когда инструмент упирается в закрытый раздел или хайд,
он возвращает `AUTH_REQUIRED`; модель вызывает `yg_login`, открывается окно Chromium со страницей
`/login/`, пользователь входит сам (капча и 2FA работают), сервер дожидается куки `xf_user`
и сохраняет сессию в `~/.yougame-mcp/cookies.json` (права 600).

`yg_logout` удаляет её. Профиль браузера живёт в `~/.yougame-mcp/browser-profile`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `YOUGAME_BASE_URL` | `https://yougame.biz` | адрес форума |
| `YOUGAME_MCP_HOME` | `~/.yougame-mcp` | куки, профиль браузера, загрузки |
| `YOUGAME_DOWNLOAD_DIR` | `<home>/downloads` | куда качать файлы |
| `YOUGAME_KB_PATH` | `<home>/kb.json` | база: инструменты, находки, сессии ресерча |
| `YOUGAME_MIN_INTERVAL_MS` | `900` | минимальная пауза между запросами |
| `YOUGAME_CACHE_TTL_MS` | `45000` | кэш HTML в памяти |
| `YOUGAME_MAX_DOWNLOAD_MB` | `1024` | потолок размера файла |
| `YOUGAME_LOGIN_TIMEOUT_SEC` | `300` | сколько ждать ручного входа |
| `YOUGAME_TIMEOUT_MS` / `YOUGAME_MAX_RETRIES` | `30000` / `3` | таймаут и ретраи запроса |

Запросы идут по одному с паузой и джиттером, при 429/5xx — бэкофф с учётом `Retry-After`.

## Проверка

```bash
npm run smoke
```

Гоняет парсеры по живому форуму (категории, раздел, тема, тема с хайдом, классификация ссылок).

```bash
npm run smoke:mcp
```

Поднимает сервер по stdio и дёргает инструменты как настоящий клиент.

```bash
npm run smoke:kb
```

Проверяет базу знаний и гейт без похода в сеть, на временной базе: план → закрытый гейт →
находки → открытый гейт → отчёт → экспорт. Все строки должны быть `ok`.

## Обновление справочников скиллов

Единственный источник правды — код: регламент в `src/workflow.ts`, хостинги в
`src/resources/hosts.ts`, каталог инструментов в `src/kb/catalog.ts`, домены и разделы
в `src/kb/domains.ts`. После правок:

```bash
npm run build && npm run gen-docs
```

Пересоберёт `skill/*/references/*.md` (`ladder.md`, `toolbase.md`, `workflow.md`, `gates.md`,
`download-hosts.md`), а с флагом `--with-map` — ещё и карту разделов с актуальными id.
Дальше `npm run install-skill -- --force`, чтобы обновить установленные копии.

```
  tools.ts            регистрация инструментов и промпта

  config.ts errors.ts
  http/               cookie jar, очередь запросов, ретраи, детект страницы входа

  resources/          реестр файлообменников и загрузчик
  kb/
    catalog.ts         встроенный каталог инструментов разработки
    domains.ts         домены задач: разделы форума, поисковые запросы, mustKnow
    store.ts           локальная база (kb.json): инструменты, находки, сессии
    research.ts        гейт «сначала ресерч»: план, проверка готовности, отчёт
skill/
  yougame-first/       гейт «сначала ресерч, потом код»
    SKILL.md
    references/        лестница решений, каталог инструментов, чек-лист, разбор примера
  yougame-research/    механика форума
    SKILL.md
    references/        регламент, хайды, хостинги, карта разделов
scripts/              смоук-тесты, генерация справочников, установка скиллов

```
