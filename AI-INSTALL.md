# yougame-mcp — инструкция для ИИ-агента

Этот файл написан для языковой модели, которая ставит пакет на машину пользователя.
Читай сверху вниз, выполняй по шагам, не пропускай проверки. Человеку нужен только
один шаг — вход на форум в окне браузера.

## Что это

Два компонента, которые работают вместе:

1. **MCP-сервер `yougame`** — доступ к форуму разработчиков yougame.biz (XenForo 2.3)
   плюс локальная база знаний: каталог инструментов разработки, находки ресерча
   и гейт, который не даёт писать код раньше ресерча.
2. **Два скилла** для клиента:
   - `yougame-first` — гейт «сначала ресерч, потом код». Срабатывает, когда пользователь
     просит **сделать** что-то из мира читов/модов/реверса, даже если форум он не упоминал.
   - `yougame-research` — механика форума: навигация, хайды, файлообменники, скачивание.

Смысл: перед тем как писать дампер, инжектор, миксин или ESP, агент обязан проверить,
не написано ли это уже — в локальной базе, в каталоге готовых инструментов и на форуме.
Свой код пишется поверх найденного и со ссылками на источники.

## Требования

| Что | Версия | Проверка |
|---|---|---|
| Node.js | ≥ 18.17 (проверено на 18.20) | `node -v` |
| npm | любой современный | `npm -v` |
| Chromium для Playwright | ставится отдельно | нужен только для входа на форум и скачиваний через браузер |

Клиент: Claude Code (CLI, десктоп, IDE) или любой другой MCP-клиент со stdio.

## Установка

### Шаг 1. Зависимости и сборка

```bash
npm install
npm run build
```

На Node 18 версии зафиксированы (`playwright@1.49.x`, `cheerio@1.0.0`) — не поднимай их,
пока Node не обновлён до 20+.

### Шаг 2. Браузер для входа

```bash
npx playwright install chromium
```

Без него работают все инструменты, кроме `yg_login` и браузерного скачивания.
Если шаг упал (нет сети, корпоративный прокси) — не блокируйся, продолжай и скажи
пользователю, что вход на форум будет недоступен.

### Шаг 3. Подключить MCP-сервер

Claude Code, из каталога пакета:

```bash
claude mcp add yougame -- node "$(pwd)/dist/index.js"
```

Или вручную: скопируй `.mcp.json.example` в `.mcp.json` и подставь абсолютный путь
до собранного `dist/index.js`.

```json
{
  "mcpServers": {
    "yougame": {
      "command": "node",
      "args": ["/абсолютный/путь/до/yougame-mcp-skills/dist/index.js"]
    }
  }
}
```

Сам `.mcp.json` в репозитории не версионируется: путь у каждой машины свой.

### Шаг 4. Поставить скиллы

```bash
npm run install-skill -- --force
```

Копирует `skill/yougame-first` и `skill/yougame-research` в `~/.claude/skills/`.
Одиночная установка: `node scripts/install-skill.mjs yougame-first --force`.

Для клиента, который не умеет скиллы: содержимое `skill/yougame-first/SKILL.md`
кладётся в системный промпт или в `CLAUDE.md` проекта — файл самодостаточен.

### Шаг 5. Перезапустить клиент

Скиллы и MCP-серверы подхватываются при старте.

### Шаг 6. Проверка

```bash
npm run smoke:kb
```

Не ходит в сеть: поднимает сервер, гоняет план → гейт → находки → отчёт на временной базе.
Все строки должны быть `ok`.

```bash
npm run smoke:mcp
```

Дёргает живой форум. `yg_search` вернёт `isError = true` до входа — это нормально.

## Что появилось у модели

### Инструменты гейта и базы

| Инструмент | Когда вызывать |
|---|---|
| `yg_plan` | **первым** для любой задачи про читы/моды/дамперы/реверс: определяет домен, отдаёт запросы, id разделов и список уже готовых инструментов |
| `yg_kb_search` | до похода на форум: не решалась ли задача раньше |
| `yg_tools` | каталог готовых инструментов по домену и виду |
| `yg_note` | записать находку: `fact`, `version`, `pitfall`, `snippet`, `gap` |
| `yg_ready` | гейт: можно ли уже писать код |
| `yg_report` | итог со ссылками — показать пользователю перед решением |
| `yg_kb_add_tool` | добавить найденный инструмент в базу |
| `yg_kb_export` | выгрузить каталог в markdown |

### Инструменты форума

`yg_guide`, `yg_auth_status`, `yg_login`, `yg_logout`, `yg_categories`, `yg_forum`,
`yg_thread`, `yg_post`, `yg_search`, `yg_page`, `yg_resources`, `yg_download`.

Регламент на лету: `yg_guide` с `topic` = `ladder` | `workflow` | `gates` | `hosts` | `tools`.

## Рабочий цикл

```
yg_plan            → домен, запросы, разделы, готовые инструменты, sessionId
  ↓ inScope=false  → обычная работа, форум не нужен
yg_kb_search       → решали ли раньше
yg_tools           → есть ли готовый инструмент (тогда свой не писать)
yg_search/yg_thread→ теория, потом исходники; комментарии обязательны
yg_note            → каждая находка со ссылкой
yg_ready           → ready=false: добрать недостающее; ready=true: писать
<код>
yg_kb_add_tool, yg_report → вернуть знание в базу
```

Гейт не тупик: если на форуме пусто — `yg_note kind="gap"`, и он откроется.
Крайний случай — `yg_ready` с `force` и обязательной причиной, которую надо озвучить
пользователю.

## Авторизация

Пароль сервер не видит и не спрашивает. При `AUTH_REQUIRED` или знаке 🔒 модель вызывает
`yg_login` — открывается настоящее окно Chromium на `/login/`, пользователь входит сам
(капча и 2FA работают). Куки сохраняются в `~/.yougame-mcp/cookies.json` (права 600),
`yg_logout` их удаляет.

Никогда не обходи капчу, оплату и ограничения ранга — сообщай о них пользователю.
Не отвечай в темах за пользователя ради открытия хайда.

## Файлы состояния

| Путь | Что |
|---|---|
| `~/.yougame-mcp/cookies.json` | сессия форума |
| `~/.yougame-mcp/browser-profile/` | профиль Chromium |
| `~/.yougame-mcp/downloads/` | скачанные файлы |
| `~/.yougame-mcp/kb.json` | база: инструменты, находки, сессии ресерча |

Переопределяются через `YOUGAME_MCP_HOME`, `YOUGAME_DOWNLOAD_DIR`, `YOUGAME_KB_PATH`.
Полный список переменных — в [README.md](README.md).

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Клиент не видит инструменты `yg_*` | не выполнен `npm run build` или в конфиге относительный путь — нужен абсолютный до `dist/index.js` |
| Скилл не срабатывает | не перезапущен клиент; проверь `~/.claude/skills/yougame-first/SKILL.md` |
| `yg_search` возвращает `AUTH_REQUIRED` | поиск на форуме закрыт для гостей — `yg_login` |
| `BROWSER_UNAVAILABLE` | не выполнен `npx playwright install chromium` |
| `yg_ready` не пускает | это штатное поведение: в ответе поле `missing` со списком, чем закрыть |
| База знаний пустая после перезапуска | проверь права на `~/.yougame-mcp/` и значение `YOUGAME_KB_PATH` |

## Обновление справочников

Тексты регламента живут в коде (`src/workflow.ts`), каталог инструментов —
в `src/kb/catalog.ts`, домены и разделы — в `src/kb/domains.ts`. Это единственный
источник правды. После правок:

```bash
npm run build && npm run gen-docs
```

Пересоберёт `skill/*/references/*.md`, включая карту разделов с актуальными id.
Затем `npm run install-skill -- --force`, чтобы обновить установленные копии.
